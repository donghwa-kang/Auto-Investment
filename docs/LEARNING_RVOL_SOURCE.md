# 학습 RVOL의 원본 봉 재계산

새 `portfolio:record` 합성 실행에서 RVOL의 원본 근거를 함께 저장하고, `learning:convert`와 학습 입력 등록 시 독립 재계산합니다. 기존 거래 조건·임계값·주문·비용 산식은 변경하지 않습니다. 실제 시장/수익성 검증이나 Codex 연결은 아닙니다.

## 사용과 정상 확인

실행 환경과 명령은 기존 [기록→변환→학습 안내](PAPER_LEARNING_BRIDGE.md#실행과-정상-확인) 그대로입니다. 별도 패키지·API 키·외부 서비스·서버 시작은 필요하지 않습니다. 프로젝트 루트에서 엔진을 새로 빌드하고 새 기록 전용 샘플을 실행하세요. 이미 등록된 실험은 재조회하며, 새 코드를 시험하려고 기존 등록 DB를 삭제하지 마세요.

- `portfolio:record`: 진입 승인 B/P 각각의 원본 RVOL 근거를 `manifest.learningJournal.featureSources`에 장부와 같은 트랜잭션으로 기록합니다.
- `learning:export`: 원본 DB는 읽기 전용입니다. 기록과 내보내기 형식 V1에 선택적 `featureSources`가 추가되며, 과거 DB에 필드를 채워 넣지 않습니다.
- `learning:convert`: 현재 출력은 `PAPER_LEARNING_CONVERSION_V2`, 학습 입력은 `ENGINE_LEARNING_RESEARCH_V2`입니다. 포함된 모든 학습 행의 RVOL 대조를 통과해야 `featuresRebuiltFromSource=true`입니다.
- `learning:register` / `learning:run`: 저장된 원본 증거에서 다시 파생 행을 계산해 검증합니다. 등록소는 보고서의 재계산 플래그와 입력 버전을 대조합니다.

고정 샘플의 기대 결과는 판단 4건, B/P 진입·청산 각각 1건입니다. B 연구 입력 1건과 RVOL 검증 완료는 정상이나 **학습/시험 표본 부족에 따른 `BLOCKED`·모델 null도 여전히 정상**입니다. 기준을 낮춰 수익성 검증으로 만들지 않습니다.

변환 보고서의 `featureChecks`에서 판단별 기록값, 재계산값, 분자·분모, 20개 비교 세션의 거래량, 315개 선택 봉 수, 근거 해시와 RVOL 보류 사유를 확인할 수 있습니다. 다른 전략·미거래를 포함한 전체 제외 사유는 `diagnostics`에 남습니다. 부분적으로 계산됐더라도 보류 사유가 있으면 그 행은 입력에 포함하지 않습니다.

## 원본 산식과 시점 계약

[공유 B/P 정의](../outputs/TRADING_STRATEGY_SPEC_v1.0.json)의 기존 기준을 적용합니다.

```text
각 15분봉 V = 해당 세션 개장 기준 같은 구간의 완료 1분봉 15개 거래량 합
분모 = 현재 세션을 제외한 직전 20개 비교 가능한 세션의 동일 위치 V 중앙값
RVOL = 현재 15분봉 V / 분모
B 진입 문턱 >= 1.5, P 진입 문턱 >= 1.2 (기존 기준 그대로)
```

- 짝수 20개 중앙값은 정렬한 10번째/11번째 값의 평균입니다. 분모 0·20개 미달은 보류합니다.
- 세션 개장 기준 슬롯을 사용합니다. 조기 종료로 그 슬롯이 존재하지 않는 세션은 제외하지만, 존재해야 하는 비교 봉의 누락을 더 오래된 세션으로 대체하지 않습니다.
- 선택한 각 1분봉의 완료 시각 ≤ 관측 시각 ≤ 수신 시각 ≤ 가용 시각 ≤ 계산 시점을 검사합니다. 미완성·중단·불가능 OHLCV는 보류합니다.
- 당시 사용 가능한 최고 revision만 선택합니다. 같은 최고 revision의 상충은 보류하며 동일 중복은 하나로 정규화합니다. 나중 도착한 정정·미래 봉은 과거 계산에 사용하지 않습니다.
- 당시 알려지고 효력이 발생한 확인된 분할만 반영합니다. 과거 거래량은 분할 비율만큼 곱하고 원본 거래량은 그대로 보관합니다. 취소/정정·중복 효력·미지원 기업행동을 구분합니다.
- 재계산은 전략의 `aggregate`·`indicators`·`median` 함수를 호출하지 않습니다. 같은 Decimal 40자리/ROUND_HALF_EVEN 계약으로 별도 구현하며, 표시 반올림 없이 trace 원문과 비교합니다. 모델에 전달할 때만 기존 FLOAT64 연구 특징으로 변환합니다.

## 저장하는 근거와 확인 범위

`LEARNING_RVOL_SOURCE_V1`에는 종목·시장/출처/데이터셋, 당시 공개된 세션 목록, RVOL에 필요한 현재 15개 + 비교 300개 원본 OHLCV/정정/수신 시각, 유효 분할과 확인 범위, 계산/신호 시각을 보존합니다. 과거 전체 120세션의 모든 봉을 복제하지 않습니다. 전체 이력·벤치마크 검사와 거래 판단은 기존 신호 재생기가 담당합니다.

판단 ID, 자료 버전, 주문 스냅샷의 원천 자료 해시, 전략/시험 정밀도 프로필과 근거 내용 해시를 연결합니다. 캡처 실패나 journal 용량 초과는 해당 명령의 장부와 함께 롤백합니다. 동일 명령 재실행은 기록을 중복 생성하지 않습니다. 기존 웹·기록 미활성 실행은 이 수집을 자동으로 켜지 않습니다.

이 대조는 **저장된 RVOL 관련 부분 자료의 재현성**입니다. 전체 원천 이력 해시를 이 부분 자료만으로 재구성하거나 공급자의 진위를 인증하는 것은 아닙니다. 로컬 관리자가 자료·시각·해시 전체를 일관되게 위조하는 경우까지 막는 전자서명이 아닙니다. 다른 지표, 벤치마크, 모집단, 뉴스 또는 전체 전략의 독립 재계산 완료를 뜻하지 않습니다.

## 과거 입력과 실패 처리

| 상태                                      | 처리                                                              |
| ----------------------------------------- | ----------------------------------------------------------------- |
| 새 기록의 원본·trace 일치                 | V2 연구 입력 생성; 거래/모델 승격은 없음                          |
| 원본 누락·잘못된 시점·상충·trace 불일치   | 해당 학습 행 보류; 사유·원본 보존                                 |
| 봉/정책/숫자 프로필·상위 증거 스키마 손상 | 해당 행 보류 또는 입력 자체 거절; 가짜 값 생성 없음               |
| 과거 내보내기에 featureSources 없음       | 새 변환은 `RVOL_SOURCE_MISSING_OR_DUPLICATE`; 과거 DB 불변        |
| 이미 저장된 ENGINE_LEARNING_RESEARCH_V1   | 기존 trace-only 형식으로 조회/검증 가능; 재계산 플래그 false 유지 |
| V1을 V2로 이름만 변경                     | 등록/입력 검증 거절                                               |

315봉 제한은 RVOL V1 전용입니다. 기존 journal 8MiB·내보내기/학습 입력 16MiB 제한은 유지하므로 근거 증가로 기록 상한에 먼저 도달할 수 있습니다. 장기 용량·실시간 지연 보장은 없습니다. 기존 표본을 새 모델의 독립 검증 구간으로 재사용하는 제한도 그대로입니다.

## 개발 검증과 다음 단계

```powershell
node work/verify-learning-rvol.mjs
```

실제 명령·출력·종료 코드는 `work/learning-rvol-verification/<실행 시각>/report.json`, 실제 인계 결과는 [PROGRESS · 공개 요약](PROJECT_STATUS.md)에 기록합니다. 새 원본/연결 시험, 기존 학습/모의 엔진/신호 재생과 관련 웹 서비스 회귀를 실행합니다. 전체 제품 검사나 브라우저 E2E는 아닙니다.

다음은 다일·다실험 데이터셋의 중복/시간순 결합과 표본 확보, [사용자 요청형 Codex 보조 분석](CODEX_ANALYSIS_PLAN.md)의 연결 준비입니다. 실제 자료 권리·비용·수신 품질·최종 holdout·장기 전진 모의·수익성·실계좌는 계속 미검증입니다.
