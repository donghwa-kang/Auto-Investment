# 사용자 요청형 Codex 보조 분석 — 계획

2026-09-14 사용자 선택: 별도 OpenAI API 과금 연결보다 개인 Codex 구독을 활용하는 선택형 분석을 우선 검토합니다. **실제 Codex 연결·인증·추가 모델 실행은 아직 없습니다.** 같은 날 후속 [로컬 모형 연결](CODEX_ANALYSIS_MOCK.md)에서 합성 자료 확인/승인 버튼·전용 저장소·결정적 모형·구조화 검증을 구현했습니다. 아래 실제 연결 계약과 구분하며 원본 거래 정책의 LLM 주문/정책 편집 금지와 기존 검증 문턱은 그대로입니다.

## 공식 근거와 확인할 조건

OpenAI Docs의 [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)는 로컬 Codex를 내부 도구/앱에 통합하는 인터페이스를 설명합니다. [인증 문서](https://learn.chatgpt.com/docs/auth)는 ChatGPT 로그인 기반 구독 이용과 API 키 기반 종량제를 구분합니다. [App Server](https://learn.chatgpt.com/docs/app-server)는 사용자 로그인·승인·대화 연동을 제공합니다. 특정 전송 방식/명령의 실험 상태와 지원 버전은 구현 전에 다시 확인합니다.

구독 사용량도 한도가 있으며 기존 Codex 작업과 공유될 수 있습니다. 한도·추가 크레딧은 [공식 사용량 안내](https://learn.chatgpt.com/docs/pricing)를 따릅니다. 후속 도움말 검사에서 로컬 버전 `0.154.0-alpha.6.2`를 확인했지만 인증/잔여 한도/실제 통신 호환성은 검사하지 않았습니다. API 결제가 필요 없다는 이유로 무제한·추가 비용 0·무중단을 보장하지 않습니다.

## 후속 구현 계약

1. 기본은 연결 꺼짐입니다. 사용자가 분석 작업마다 요청해야 합니다. 현재 거래 기준·대상·기간·전송 자료 목록/해시·요청 ID를 먼저 고정합니다. 이 대화의 기억이 자동으로 전달된다고 가정하지 않습니다.
2. 분석 승인과 거래 적용 승인을 구분합니다. 분석 대상은 뉴스/공시 근거 정리·거래 복기·검증 실험 제안입니다. 모델에 직접 주문·자금 이동·정책 파일 편집·보호 해제 권한을 주지 않습니다.
3. 연결 전 **ChatGPT 구독 인증 모드**를 확인합니다. API 키·다른 공급자로의 자동 전환, 추가 크레딧 구입/리셋 사용은 금지합니다. 로그인 토큰을 추출해 일반 API 키처럼 사용하지 않습니다.
4. 분석 전용 작업 공간에 승인된 최소 자료만 전달합니다. 실제 증권 키·계좌번호·사용자 전체 파일을 보내지 않습니다. 읽기/쓰기·명령·네트워크·도구 권한은 OS/샌드박스 경계로 제한하며 프롬프트 지시만으로 보호했다고 표시하지 않습니다.
5. 호출 횟수·실행 시간·사용량을 제한하고 자동 반복/재시도를 막습니다. 승인 취소는 앞으로의 실행을 멈추는 것이며 이미 소비한 사용량/전송 자료를 되돌리는 것은 아닙니다.
6. 결과는 구조화된 제안으로 받고 출처 ID·시점·필수 필드·숫자·입력 해시를 검증합니다. 원문·모델/설정·파서 버전·출력·오류·사용량을 기록합니다. 최신 사실이나 주가 예측을 모델 기억만으로 채우지 않습니다.
7. 실행 중 정책 파일/활성 모델을 자동 교체하지 않습니다. 제안은 별도 실험으로 검증하고 기존 승격 절차를 통과해야 합니다. 사용자 확인 하나로 원본 검증 문턱을 건너뛰지 않습니다.
8. Codex 종료·한도·오류가 나도 기존 위험관리/보유 관리는 독립 실행됩니다. 필수 분석/예측이 없는 전략은 신규 진입을 보류합니다. AI를 껐다는 이유로 미검증 Q/QT나 다른 전략으로 자동 전환하지 않습니다.
