# 2차 검증 범위 정정과 현재 시장 확인

이 문서는 후보 범위를 정정한 당시의 기록이다. 이후 같은 날 사용자 승인으로 수행한 실제 토스 시세 연결 결과와 현재 한계는 [시세 연결·모의 사전점검 안내](TOSS_MARKET_CHECK.md)를 우선한다.

사용자 요청: 현재 시장을 기준으로 검증하되, 레버리지 전체가 아닌 기본예탁금 3,000만 원 이상이 필요한 단일종목 레버리지를 제외한다. SOXL은 이 금지 대상과 구분한다. 이번 변경은 후보 범위 분류와 표시이며 실제 시세 공급·계좌·유료 AI·실주문 연결은 아니다.

## 후보 범위

| 구분 | 사용자 제한 | 이번 구현 상태 |
| --- | --- | --- |
| 3,000만 원 이상 예탁금이 필요한 단일종목 레버리지 | 제외 | 후보 분류 함수에서 EXCLUDED_BY_USER |
| SOXL: 반도체 지수 일일 3배 ETF | 레버리지라는 이유만으로 제외하지 않음 | INCLUDED_FOR_VALIDATION, 실거래 자격/승인 UNVERIFIED |
| SOXX: 반도체 지수 일반 ETF | 검증 후보 | INCLUDED_FOR_VALIDATION, 실거래 자격/승인 UNVERIFIED |
| 기초자산 분류·단일종목 레버리지 예탁금 미확인 | 임의 추정하지 않음 | CLASSIFICATION_REQUIRED |

SOXL은 NYSE Semiconductor Index의 일일 수익률 300%를 목표로 한다. 단일 기업 주식의 레버리지 상품이 아니며, 여러 날 누적 수익률의 3배를 보장하지 않는다. [운용사 상품 설명](https://www.direxion.com/product/daily-semiconductor-bull-bear-3x-etfs).

사용자의 3,000만 원 단일종목 제외 의도와 별도로, 금융위원회는 일반 해외상장 레버리지 ETF에도 기본예탁금 1,000만 원 제도를 설명한다. 따라서 운용금 500만 원이라는 정보만으로 SOXL의 계좌별 매매 자격을 단정하지 않는다. 예외·기존 투자자 적용·교육·증권사 약정과 예탁금 산정은 미확인이다. 운용 배정금과 계좌 전체의 적격 예탁금도 별개다. [일반 해외 레버리지 제도 설명](https://www.fsc.go.kr/no010102/87468), [단일종목 현금 3,000만 원 및 교육·모의거래 안내](https://www.fsc.go.kr/no010101/87512).

이 앱에서 수행한 합성 시험은 제도상 의무 모의거래 이수 증명이 아니다. 조사를 많이 수행했다는 사실만으로 상품별 예측·체결·계좌 검증이 통과되는 것도 아니다.

## 현재 시장: 2026-09-11 15:57–16:03 서울 기준 확인

- KRX 정규장 09:00–15:30은 종료됐다. 시간외/NXT는 별도이며 이 확인을 모든 세션의 휴장으로 해석하지 않는다. [거래소 운영 시간](https://regulation.krx.co.kr/contents/RGL/03/03020401/RGL03020401.jsp).
- 미국 정규장은 아직 시작 전이다. NYSE 공식 달력/정규장 09:30–16:00 ET와 해당 날짜의 서머타임을 적용하면 오늘 22:30부터 다음 날 05:00까지 KST다. 사전 공표 시간 기준이며 당일 거래 중단까지 확인한 실시간 시장 신호는 아니다. [NYSE 달력과 시간](https://www.nyse.com/trade/hours-calendars).
- 따라서 지금 열려 있는 시장을 임의로 선택해 정규장 B/P를 시간외·야간장에 적용하지 않는다. 실제 가격/뉴스/호가 공급을 먼저 준비하고 거래소 세션별로 판정해야 한다.
- 이번에 열람한 SOXL 운용사 페이지의 가격 기준일은 9월 9일이다. 이를 9월 11일 현재가나 실시간 호가로 사용하지 않는다. 실시간 가격·현재 매수 신호는 이번에 취득/판정하지 않았다.

## 실제 시세 기반 모의검증의 다음 조건

토스 공식 가이드는 KR/US 시세·호가·체결·환율·시장 달력과 WebSocket을 설명하며 OAuth 접근 토큰을 요구한다. 계좌·자산·주문 API에는 별도 계좌 헤더가 필요하다. 이번에는 공식 공개 문서만 읽었고 토큰 발급·계좌 조회·WebSocket 연결은 하지 않았다. [공식 API 안내](https://developers.tossinvest.com/llms.txt).

1. 별도 시세 수집 프로세스의 인증/조회 전용 허용 경로를 확정한다. 주문·잔고·취소·환전 경로는 제외한다. 시세용 인증 정보는 대화·브라우저 저장소·일반 로그에 넣지 않는다.
2. 과거 완료 1분봉·호가 이력의 가용 기간, 시점/수신/정정 기록, 이용 권리와 비용을 확인한다. 세부 API 문서 일부는 도구의 안전 검사 또는 형식 지원 제약으로 조회하지 못했고 재시도 우회하지 않았다. 공급 가능 기간·요금은 아직 확정하지 않았다.
3. SOXL에 대해서는 실제 SOXL 자료와 별도 상품/비용/체결/예측 프로필을 정의한다. SOXX 가격에 3을 곱하거나 합성 예측 값을 실제 예측으로 사용하지 않는다. 기존 B/P를 무검증으로 승계하지 않는다.
4. 원본 위험 한도·정규장/30초 신호 기한·시점 검증·표본 외·봉인·60거래일 전진 모의 조건을 유지한다. 후보 포함을 원본 LIVE 승격 조건 우회로 사용하지 않는다.

현재 `src/core/research-scope.ts`는 후보 분류 함수이고 실제 전 시장 스캐너나 매수 승인기가 아니다. 앱 주문 엔진은 여전히 합성 종목만 다룬다. 예탁금이 불명확한 지수형 ETF도 연구 후보로는 포함할 수 있지만 그 결과로 매매 자격을 true로 설정하지 않는다.

## 변경 및 검증 범위

원본 outputs 파일은 보존한다. 새 `profiles/research-scope-v1.json`과 후보 분류 함수, 테마 카드의 후보/권한 표시를 추가·변경했다. 이전 문서의 OBSERVE_ONLY는 당시 정책 기록으로 남기고 새 사용자 요청과 구분한다. 실행 중인 사용자 엔진·실험 DB는 변경/재시작하지 않는다.

이번 변경 후 실제 실행한 검사:

- `npm run build`: 타입 검사·엔진 컴파일·프런트엔드 빌드 성공.
- `npm run lint`, `npm run format:check`: 성공. 새 연구 범위 JSON은 별도 Prettier 검사 대상으로 확인한다.
- `node --test --test-concurrency=1 dist/runtime/tests/core.test.js dist/runtime/tests/research-scope.test.js`: 71/71 통과, 실패·건너뜀 0. SCOPE-01–03과 THEME-01을 포함한다.
- `npm run test:e2e`: Edge 브라우저 2/2 통과. 테마 화면의 SOXL 후보/자격 분리 표시와 스크린샷을 확인했다.
- `npm run verify:originals`: 원본 37/37 SHA-256 일치.
- README와 관련 문서 4개의 내부 링크 19개 경로 실재·Markdown 렌더링 구조·가로 넘침 없음을 확인했다. 새 범위 문서·README·요구 대응표의 PNG를 직접 확인했다. GitHub 화면 또는 기존 미완료 정책 문서의 시각 검토를 완료했다는 뜻은 아니다.

전체 회귀 검사 108개 및 기존 정책 정적 검사 248개는 이전 1차 기록이며 이번 변경 후 전부 재실행하지 않았다. 실행 중인 사용자 실험과 인증 파일에 영향을 줄 수 있는 종료 시험은 이번 집중 검사에서 제외했다. 실제 시세 수신·백테스트 수익성·계좌 자격·실주문·유료 AI·API 이용 비용/권리는 미검증이다.
