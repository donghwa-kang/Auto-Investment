# 토스 실제 시세 연결·모의 사전점검

기본 웹 앱의 합성 실험과 분리된 **한 번 실행하는 시세 조회 CLI**다. 토스에 인증하지만 계좌·주문·환전은 호출하지 않는다. 현재 구현은 실제 시세 수신과 모의매매 전제조건 점검까지이며, 지속 자동매매·전체 전략 평가·가상 체결 구현을 완료한 것으로 해석하지 않는다.

## 사용 방법

프로젝트 루트에서 기존 `npm ci --ignore-scripts` 설치가 끝난 Node.js 24 환경을 사용한다. `.env` 자동 로딩은 없다. 기존 `npm start` 서버를 끄거나 합성 DB를 초기화할 필요가 없다.

```powershell
npm run build:engine
$env:TRADING_MODE = 'PAPER'
$env:LIVE_ENABLED = 'false'
$env:TOSS_MARKET_DATA_ONLY = 'true'
$env:TOSS_CREDENTIAL_FILE = 'C:\secure-local\toss-credentials.txt'
npm run market:check
```

위 파일 경로는 예시다. 자신이 보관한 인증 파일의 실제 경로로 바꾼다. 이 명령은 경로에 파일을 만들지 않는다. 인증 파일은 `CLIENT_ID`/`CLIENT_SECRET` 라벨 다음 줄에 해당 값을 두거나 `라벨=값` 형식을 사용한다. 비밀값을 채팅·명령행·로그·이 문서에 쓰지 않는다. 현재 CLI는 UTF-8 텍스트만 지원한다. 파일 오류는 값이나 경로를 출력하지 않고 `CREDENTIAL_FILE_INVALID`로 종료한다.

| 변수 | 용도 | 기본값/필수 | 비밀값 여부 |
| --- | --- | --- | --- |
| `TOSS_MARKET_DATA_ONLY` | 외부 시세 연결 명시 선택 | 정확히 `true` 필수 | 아님 |
| `TOSS_CREDENTIAL_FILE` | 로컬 인증 파일 경로 | 필수, 기본 경로 없음 | 경로 자체는 키가 아니지만 개인 경로 보호 필요 |
| `TRADING_MODE` | 실거래 모드 거부 | PAPER, LIVE 거절 | 아님 |
| `LIVE_ENABLED` | 실거래 활성화 시도 거부 | 미설정/false, true 거절 | 아님 |

성공 시 `CONNECTED_SNAPSHOT_ONLY`, `realOrdersEnabled:false`, `paperOrderCount:0`을 표시하고 종료 코드 0으로 끝난다. 이는 연결 성공이지 모의 체결/전략 수익성 검증 성공이 아니다. `data/market-checks/` 아래 고유 파일명으로 자료·수신 시각·판정·요청 경로/HTTP 상태를 저장하며 기존 파일을 덮어쓰지 않는다. 인증 또는 수신 실패 시 실패 코드를 남기고 종료 코드 1로 끝난다. 자동 재시도하지 않는다.

보고서의 가상 KRW 500만 원/USD 0은 이 사전점검의 별도 시험 장부다. 사용자 실제 잔고를 조회하거나 기존 합성 장부를 바꾸지 않는다. 가상 달러 배정 UI나 실제 환전은 수행하지 않는다.

## 연결 및 키 보호 경계

- 공식 호스트 `https://openapi.tossinvest.com`만 사용한다. 임의 URL·헤더·계좌번호를 전달하는 인터페이스가 없다.
- 허용 요청: `POST /oauth2/token`, `GET /api/v1/prices`, `/orderbook`, `/candles`, `/market-calendar/US`만이다. 호출은 총 7회이며 인스턴스별 8회 상한과 요청별 15초 제한을 둔다. 리디렉션·추가 종목·잘못된 날짜는 거부한다.
- API 키/토큰은 프로세스 메모리에만 사용하고 파일·로그에 저장하지 않는다. 토큰 응답과 오류 원문, 응답 헤더를 보고서에 넣지 않으며 시세도 허용된 필드만 저장한다. 종료 후 사용 참조를 해제하되 JavaScript 메모리의 암호학적 완전 삭제를 보장하지는 않는다.
- 원본 메모장 파일은 읽기만 한다. OneDrive 동기화 대상 원본의 이동/삭제, Windows 자격증명 저장소 이관, ACL 강화는 이번에 수행하지 않았다. `0600` 요청만으로 Windows ACL 격리가 보장된다고 주장하지 않는다.
- 토스 발급 토큰 자체가 조회 전용으로 제한되는 것은 아니다. 프로그램에서 호출 경로를 제한한 것이며, 계좌/주문/취소/환전 메서드는 구현하지 않았다. OS 방화벽 격리는 제공하지 않는다.
- 공식 명세상 새 토큰 발급은 같은 client의 이전 토큰을 무효화한다. 이 시험에서는 사용자에게 같은 키를 다른 프로그램에서 사용하지 않는다는 답변을 받은 뒤 인증했다. 재실행 전에도 다른 프로그램과의 충돌을 고려해야 한다.

공식 계약은 [토스 REST OpenAPI 1.2.15](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 확인했다. 이전 llms/overview 문서의 안전 차단을 우회한 것이 아니라 별도 공개 REST 스키마를 정상 열람했다. 미국 달력 `date`는 미국 현지 날짜이며, 개별 주식 `1m` 캔들의 timestamp는 **봉 종료 시각**이다. 현재/미래 종료 봉은 수신 완료 봉 수에서 제외한다. 현재 구현은 장기 과거 페이지 수집과 기업행동/벤치마크/기관/뉴스 조사는 하지 않는다.

## 2026-09-11 실제 실행 결과

16:28:42–16:28:43 KST에 인증 1회와 시세/달력 조회 6회가 모두 HTTP 200으로 응답했다. 조회 시점의 가격이며 이후 현재가로 재사용하지 않는다.

| 종목 | 수신 최근 가격 USD | 완료 1분봉 수 | 모의 판정 |
| --- | --- | --- | --- |
| SOXL | 116.84 | 199 | ABSTAIN, 수량 0 |
| SOXX | 519.70 | 199 | ABSTAIN, 수량 0 |

보류 이유:

- 당시 미국 정규장 밖이었다. 실제 달력 응답으로 판정했다.
- 실제 자료용 예측 프로필, 상품 비용/체결 프로필, 시점별 장기 과거 자료/벤치마크, 기업행동/이벤트 자료가 없다. 기존 TEST_ONLY 합성 예측/비용을 실제 시세에 적용하지 않는다.
- 가상 달러가 배정되지 않았다. 원화를 달러 현금으로 간주하지 않는다.
- SOXX 호가는 점검 시 약 2.7초 전 자료여서 원본 2초 신선도 기준도 초과했다. 연결 시험을 통과시키기 위해 이 한도를 완화하지 않았다.

**실주문 0건, 계좌/잔고 조회 0건, 환전 0건, 모의 체결 0건.** 짧은 점검 프로세스는 종료됐고 지속 수집/자동매매 중인 상태가 아니다. 기존 4173 웹 앱은 계속 합성 데이터 화면이며 실제 가격을 표시하도록 연결한 것은 아니다. 원본 정책은 보존한다.

실행 원본 기록은 로컬 `data/market-checks/2026-09-11T07-28-43.714Z-ef793a93-82ec-4224-ad48-86e33acaf968.json`에 있다. 계좌 키나 토큰은 포함하지 않는다. 데이터 이용권/요금·재배포 권리를 별도로 확정한 것은 아니며 외부 공개·유료 가입은 하지 않았다.

## 검증·미검증

재현 가능한 집중 검사:

```powershell
npm run typecheck
npm run lint
npm run format:check
npm run build:engine
node --test --test-concurrency=1 dist/runtime/tests/market-data.test.js dist/runtime/tests/core.test.js dist/runtime/tests/research-scope.test.js
npm run verify:originals
```

실행 결과: 타입·린트·형식·엔진 빌드 성공, 새 시세 검사 14개 포함 집중 검사 **85/85 통과**(실패·건너뜀 0), 원본 **37/37 해시 일치**. README/안내의 내부 링크 12개 실재 및 Markdown 구조·가로 넘침 없음을 확인하고 PNG를 직접 검토했다. 변경/수신 파일 9개에서 실제 CLIENT_ID/CLIENT_SECRET 문자열과 일치하는 값이 없음을 별도 로컬 검사했다. 전체 저장소·Git 기록·모든 비밀값 형식의 검사를 뜻하지 않는다.

추가 검사에는 키 형식/중복, 고정 호스트·계좌 헤더 부재, 키/토큰 오류 비노출, 302/401/403/429/500 중단, 과대 응답·잘못된 가격/통화, 요청 상한, 미래/오래된 호가·교차 호가·미완성 봉·필수 프로필 누락 보류를 포함한다. 처음 검사에서 동기/비동기 예외 시험 및 Decimal 예외 비노출 문제가 발견돼 수정 후 다시 검사했다. 별도로 실제 CLI 자식 프로세스 4개에서 명시 연결 미선택·키 경로 없음·LIVE_ENABLED=true·TRADING_MODE=LIVE 시작 거부(종료 코드 1)를 확인했다.

이전 전체 회귀/브라우저 검사를 이번 연결 검사의 결과로 재사용하지 않는다. 완성된 실제 시세 전략 실행·표본 외 성과·장기 수집·실제 모의 체결·실거래 자격·시세 요금/이용권·비밀파일 암호화/권한 격리는 미검증 또는 미구현이다. 매매 기준 수치·원본 null·LIVE 잠금은 변경하지 않았다.
