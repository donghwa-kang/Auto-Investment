# 공개 프로젝트 상태

기준일: 2026-10-01. 비공개 `PROGRESS.md`와 로컬 실행 증거를 요약한 공개 안내입니다. 과거 기록의 모든 검사 결과를 재실행하거나 원시 로그를 공개한 문서는 아닙니다.

## 현재 개발 단계

DEV-D03-S11-B는 **3/4 = 75%, 부분 완료**입니다. 비용 코어 시험 V4의 합성 체결·운영비·D8 마감·보고·읽기 전용 입력 검증을 연결했습니다. 기존 V3와 원본 거래 정책, 10초 lease 및 기존 안전 제한은 유지합니다.

상위 DEV-D03은 **2/4 = 50%**, 실행 가이드는 **10/40 = 25%**입니다. 서로 범위가 다른 분율이므로 합산하거나 실전 준비율로 해석하지 않습니다.

- [x] 명시적인 V4 선택·구형 호환·원자료/요청 보존과 해당 인수.
- [x] 동일 Store의 체결·비용·마감 및 해당 복구·실패 경계 인수.
- [x] 별도 읽기 검증 worker·표시·로컬 다운로드와 해당 인수.
- [ ] 최초 CW-03 실패의 미확정 원인과 제한된 부하·lease/owner/epoch 경계를 정리하고 전체 인수 마감 여부 판단.

## 기존에 실제 실행한 검사

S11-B 개발 기록에서 신규 단위 11개, 기존 영향 회귀 37개, Edge 브라우저 2개가 각각 최종 통과했습니다. **여러 실행의 고유 50개**이며 마지막 변경 후 전체를 한 번에 돌린 것이 아닙니다. 중간 실패를 지우거나 반복 성공을 추가 통과 수로 세지 않았습니다.

실제 브라우저/임시 HTTP/두 worker에서 V4와 기존 V3 경로, 인증·CSRF·경로 제한, 다운로드 바이트, 새로고침·응답 유실, 검증 worker 종료 후 금융 상태 유지를 확인했습니다. 당시 엔진·웹 빌드, 타입 검사, 변경 범위 린트, 원본 37개 해시도 확인했습니다. 자세한 조건과 실패 구분은 [S11-B 보고](COST_APP_INTEGRATION.md)에 있습니다.

## 알려진 문제와 다음 작업

최초 V3 CW-03의 `FENCED_WRITER` 실패는 당시 owner/epoch/시간 계측이 없어 정확한 원인이 미확정입니다. 후속 성공이나 별도 V4 시험 경계 수정으로 과거 실패를 해결했다고 선언하지 않습니다. 다음 개발은 잔여 진단 인수이며 timeout 증가·안전 검사 완화·새 장부 기능 추가로 대체하지 않습니다.

전체 회귀·장시간/최대 입력·극단 CPU/메모리·물리 전원/디스크 장애, 실제 OS 격리, 실자료·실요율·실계좌, AI 기여도·투자 수익성은 미검증 또는 미완료입니다. 다일/월 전환·외화·환불/정정의 미정 정책도 자동 보완하지 않습니다.

## 이번 공개 준비의 검증

이번에는 공개 대상 파일만 복사한 별도 폴더와 새 의존성 설치로 확인했습니다. 기존 사용자 DB·API 키·서버는 사용하지 않았습니다.

- `npm ci --ignore-scripts --no-audit --no-fund`: 잠금 파일 기준 새 설치, 121개 패키지. 의존성 취약점 감사는 실행하지 않았습니다.
- `npm run build`: 타입 검사·엔진/시험 TypeScript 컴파일·Vite 웹 빌드 통과.
- `npm run lint`: 공개본의 전체 설정 범위 린트 통과.
- 원본 검사: 로컬 기존 목록 37/37 및 공개 목록 22/22 일치. 별도 시험 복사본에서 정책 1개 변조 시 종료 코드 1로 거절했습니다.
- 별도 임시 포트·새 저장소의 실제 다종목 CLI 기동, HTML/health 응답, 인증 전 401, 일회용 코드 로그인, 인증 후 조회, 정상 저장 종료·코드 만료 확인.
- 게시 대상 521개 파일의 제한적 비밀값·개인 경로·계좌 필드 패턴과 금지 경로를 점검했습니다. 패턴 일치는 합성 시험값·loopback 주소·인터넷 바인딩 금지 예시로 확인했습니다. 전체 보안 감사가 아닙니다.
- 상대 파일 링크는 공개 대상 기준으로 확인했습니다. 불변 정책 원본의 비공개 `work/`를 가리키는 4개 링크는 의도적으로 그대로 두며 README에 제외 사유를 명시했습니다. 외부 링크와 모든 heading anchor를 재검증하지 않았습니다.

이번 게시 작업에서는 매매 런타임·기존 테스트·원본 정책의 바이트를 변경하지 않았습니다. 공개용 문서/제외 규칙/해시 목록과 검사 스크립트의 공개 목록 선택만 보완했습니다. 전체 `npm test`/`verify`, 브라우저 E2E·시각 재검사, 실투자 검증은 이번에 실행하지 않았습니다.

## 과거 문서 읽는 법

`docs/`와 `outputs/`에는 계획·설계·그 시점의 결과가 함께 있습니다. 문서 날짜와 미완료 표시를 확인하세요. 과거 `PROGRESS` 링크는 이 공개 요약으로 연결되며 상세 로컬 일지와 동등하지 않습니다. 비공개 `work/` 증거·스크립트는 경로 설명으로만 남고, 불변 `outputs/`의 옛 링크는 일부 제외 파일을 가리킬 수 있습니다. 공개본에서 없는 경로의 명령을 실행하지 마세요.

실제 계좌·시세·주문·유료 AI 연결 승인이나 데이터 재배포 권한은 이 공개로 부여되지 않습니다.
