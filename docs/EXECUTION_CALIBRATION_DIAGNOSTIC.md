## 📋 제공 범위

[초기 스트레스 시험](EXECUTION_STRESS.md)의 500ms·2틱은 합성 가정입니다. 이번 기능은 [기존 모의 수신 변환기](TOSS_OFFLINE_INGEST.md)를 재사용해 무엇을 관측했고 무엇을 아직 알 수 없는지 나눕니다. 실제 자료를 내려받거나, 합성 표시로 바꾸어 수용하거나, 스트레스·거래·학습 설정에 자동 적용하지 않습니다.

제공 기능은 `reviewMockExecutionEvidence()` 개발 API와 고정 샘플 CLI입니다. 기존 웹 앱, 거래 엔진, 정책 원본, 비용 장부, 수집/학습 경로는 바꾸지 않습니다. 새 의존성도 없습니다. [기존 G1/G2](investment-data-contract-v1/SOURCE_REGISTER.md)의 절차를 중복 구현하거나 문서만으로 승인하지 않습니다.

## 🔍 공식 공개 자료 재확인

2026-09-21 공개 문서를 조회한 결과입니다. 기술 기능의 존재와 사용자에게 적용되는 이용권·요금·품질을 구분합니다. 인증·계좌 조회·호가 API 호출·상품 신청·약관 동의는 하지 않았습니다.

| 토스 실시간 채널   | REST와 별도 WS 명세 안내         | WS 연결·재연결·누락 복구 검증              |

토스 관련 기능·필드의 근거는 공식 REST 명세입니다.[^1] `commissionRate`의 소수 비율을 bps로 쓰려면 10,000을 곱해야 합니다. 문서의 예시 숫자를 사용자의 수수료로 채택하지 않습니다. 토스의 별도 API 조회요금과 우리 용도의 로컬 보관·비표시 분석 권한은 **미확인 유지**입니다.

공개 브라우저에서 확인한 토스 약관 선택본(2026-08-12)은 본인 매매 목적과 제3자 제공 등의 제한을 규정합니다. 회사 측 거래정보 보관 의무를 사용자 호가의 무기한 저장권으로 해석하지 않습니다.[^2] 별도 WS 명세 본문은 이번 도구에서 접근하지 못했으므로 상세 메시지·유실 복구 규격은 확인 완료로 표시하지 않습니다.

KRX 공개 API 약관과 별도 시세 분배 절차는 구분합니다.[^3][^4] 일별 봉·공시만으로 장중 호가, 체결 대기열이나 주문 지연을 복원할 수 없다는 것은 필요한 입력을 비교한 설계 판단입니다. KRX와 연결하기만 하면 모든 실제 비용이 정확해진다는 의미가 아닙니다. 법적 이용 허가를 확정하는 문서도 아닙니다.

## ⚙️ 진단 입력과 계산 계약

[개발 API](../src/core/execution-evidence.ts)는 `OFFLINE_EXECUTION_EVIDENCE_V1`, `TEST_ONLY`, 단일 대상 종목과 예시 수량, nullable `tickSpec`, 기존 `MOCK_CONTRACT/MOCK_RESPONSE` 수신 입력을 받습니다. 실제 자료 표시, 미지 필드·페이지 계획·잘못된 통화/시간 형식은 거절합니다. 보고서 해시는 내용을 결합할 뿐 출처 진위를 인증하지 않습니다.

미래 가용 호가는 통계에서 제외합니다. 과거 호가는 각 관측의 가용시각에서 기존 2초 호가 검사를 수행하고, 보고 종료까지 알려진 같은 시각의 중복·상충을 대조합니다. 이것은 과거 수신 진단이지 현재 거래에 과거 호가를 허용하는 기능이 아닙니다. 서로 다른 시각의 관측은 같은 가격이어도 유지합니다. 비호가 입력은 무시한 수를 보고하고, 다른 종목의 호가는 차단합니다.

| 출력                         | 정의                                | 해석 제한                           |
| ---------------------------- | ----------------------------------- | ----------------------------------- |
| `spreadBps`                  | `(ask−bid) / ((ask+bid)/2) × 10000` | 유효 고유 호가 표본의 기술통계      |
| `responseIntervalMs`         | RESPONSE의 수신−요청 시각           | HTTP 실패도 포함, 주문 지연 아님    |
| `timeoutIntervalMs`          | TIMEOUT의 종료−요청 시각            | 완료 응답 지연과 별도 보고          |
| `providerReportedAgeMs`      | 수신−공급자 표시시각                | 시계 동기/원천 의미 미검증          |
| `oneTickForQuantity`         | `수량 × 틱 크기`                    | 해당 통화 금액, 추가 장부 비용 아님 |
| `oneTickBps`                 | `틱 크기 / ask × 10000`             | 같은 가격이면 수량과 무관           |
| `roundTripOneTickPerSideBps` | 위 비율의 2배                       | 동일 기준가격의 양쪽1틱 산술 사례   |

통계는 최솟값·중앙값(짝수는 두 값 평균)·nearest-rank p95·최댓값입니다. 호가 중복은 가격 표본에서 제외하되 별개의 조회 응답 간격은 남깁니다. 시간가중 통계·독립표본·신뢰구간·시장 국면 커버리지를 주장하지 않습니다. 표본 한 개도 산술상 보고할 수 있지만 보정 충분성의 근거는 아닙니다.

틱 규격은 증거 ID, 당시 가용시각, 효력 `[from, until)`, 가격대 `[priceFrom, priceUntil)`, tick/lot을 요구합니다. 최우선 bid/ask가 모두 규격에 맞고 예시 수량이 lot 배수이며 양쪽 표시 잔량을 넘지 않을 때만 틱 비용을 계산합니다. 최우선 같은 가격 레벨이 여러 개인 경우 합산을 추정하지 않고 보류합니다. 실제 가격대별 틱표·상품별 자격·원본 거래량/노출 한도를 이 진단이 대체하지 않습니다.

수수료·세금·환전비·운영비와 호가 대기열·충격·체결 확률은 계산하지 않습니다. `feeEstimate`, `orderLatencyEstimate`, `cancellationLatencyEstimate`는 `null`이고, `collectionAuthorized`, `realCalibrationReady`, `engineProfileApplied`, `learningEligible`, `liveEnabled`는 항상 `false`입니다. 미확인을 비용 0원으로 바꾸지 않습니다.

## 🔧 실행과 정상 결과

프로젝트 루트 PowerShell에서 [기존 설치 환경](../README.md#실행-환경)을 사용합니다.

```powershell
npm run build:engine
node dist/runtime/src/server/execution-evidence-cli.js
```

추가 인수는 받지 않습니다. 기존 `fixtures/source-ingest-v1.json`의 US `TEST` 모의 호가와 명시적 합성 tick 0.01·lot 1·수량4만 사용합니다. 정상 출력은 `OFFLINE_EXECUTION_EVIDENCE_COMPLETE`와 새 `work/execution-evidence-runs/run-*/report.json`입니다. 기존 보고서를 덮어쓰지 않습니다. 잘못된 인수·LIVE 설정·실패는 `EXECUTION_EVIDENCE_SAMPLE_FAILED`, 종료 코드1입니다. 보고서의 `HAS_BLOCKS`는 진단이 끝났지만 입력 보류가 있다는 뜻입니다.

고정 예시는 bid101·ask101.1 USD이며 스프레드는 약9.89609bps, 수량4의1틱 금액은0.04USD, 진입대금은404.4USD입니다. 조회 응답 간격1000ms는 이 픽스처의 시간 차이일 뿐 토스 실측 지연이 아닙니다. 신규 웹 화면이나 실자료 입력 CLI는 없습니다.

```powershell
node --test --test-concurrency=1 dist/runtime/tests/execution-evidence.test.js dist/runtime/tests/execution-evidence-cli.test.js
```

실제 검사 결과와 원본 보존은 [진행 기록 · 공개 요약](PROJECT_STATUS.md)에 남깁니다. 실제 자료 수집, WS 어댑터, 권리/요금 자동 인증, 실제 보정값 도출·프로필 승격, 투자 성과·OS 격리 검증은 완료하지 않았습니다.
