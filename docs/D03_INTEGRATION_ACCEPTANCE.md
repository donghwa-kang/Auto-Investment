S9-A 후속 설계(2026-09-30): [비영 이력의 후보 심사 설계](COST_HISTORY_ADMISSION_DESIGN.md)에서 다음 S9-B 범위와 HA-01~16을 정의했다. 기존 추정기/비선형 계산기는 이력을 받지만 새 로컬 승인/신호/접수 경로에는 입력 연결이 없다. 첫 비용 사건 HOLD와 당월 이전 누계0 계약을 보존하기 위해 새 KRW 위험월 첫 위험일·첫 후보·이전 위험월의 완료20일/N>0 합성 이력만 연결 대상으로 한다. 월중 이관/비용 후 연속 진입은 여전히 미지원이다. 아래 단계별 상태는 S6 당시 기록이며 설계 완료를 제품 인수나 D03 완료로 합산하지 않는다.

## 📋 결론과 이 문서의 사용법

지금 필요한 것은 새 장부를 더 만드는 일이 아니라 **V3 자동매매, V4 운영비·마감, 학습 입력 사이의 연결**이다. [S5 화면](COST_WEB_LAB.md)은 V3 합성 거래와 동일 비용 근거의 보고/HOLD까지 제공한다. 운영비를 포함한 자동매매·학습 입력까지 연결됐다는 뜻은 아니다.

이 문서는 [실행 가이드](DEVELOPMENT_EXECUTION_GUIDE_v1.md)의 D03-03/04를 세분화한 인수 지도다. 원래 체크 항목·정책·진행률을 바꾸지 않는다. 이번 산출물은 소스 대조·기존 경계 시험 재실행·다음 작업 지시이며 **제품 기능 추가는 없다**. 아래 ‘남은 인수’와 S7 조건은 미구현/미실행 계획이다. 과거 시험 결과와 이번 재실행 결과는 [PROGRESS · 공개 요약](PROJECT_STATUS.md)에서 구분한다.

### S7의 정확한 한계와 인수 조건

첫 S7 정상 경로는 **명시 무운영비 조건에서 이미 승인·인계된 한 거래**에 합성 운영비 의무가 발생하는 경우다. 현재 V4는 첫 운영비 사건부터 신규 진입을 막으므로 그 제한을 유지한다. 비영 비용 이력이 있는 계좌에서 새 후보를 계속 승인하는 기능은 S7 완료에 포함하지 않는다. 그 기능은 완료20위험일 근거·후보 추정·접수 직전 재검사가 같은 비용 계약을 사용하도록 후속 인수해야 한다.

1. 기존 B/P 신호·상품/가격 근거를 새 명시 V4 실행에 결합한다. 구형 V3 config/기록을 수정하지 않고, 새 지원 조합의 버전·근거를 검증한다.
2. 부분 매수 후 비영 운영비를 인식한다. 같은 초기 현금에서 채무를 한 번 인식하고 연결 예약만 상계한다. 운영비 추정·보고 배분을 현금에서 다시 빼지 않는다.
3. 운영비/HOLD 중 손절·목표·시간 트리거, 미확정 취소/매도, 입력 단절을 검사한다. AI/외부 I/O 없이 유효 체결과 보호 처리를 유지한다. 오래된 호가로 체결하거나 타이머로 결제 증거를 만들지 않는다.
4. 확정 배분 전 최종 손익은 null이며 신규 진입과 손실 카운터의 임의 초기화를 막는다. 알려진 과다 손실·기존 중지를 그대로 보존한다. 루프 종료 뒤에도 미지급/미수는 남을 수 있다.
5. 같은 명령/체결의 재전송은 기존 영수증으로 복구한다. 내용 충돌·stale expectedState·쓰기/COMMIT 실패·epoch 교체를 기존 단일 저장 경계에서 검사한다. 일반 DB 재열기와 프로세스 강제 종료 시험을 구별해 보고한다.
6. 기존 V3/S5·운영비/마감 회귀를 실행하고 명시 지원 범위·잔여 한계를 기록한다. S7은 개발자용 연결이며 S5 화면의 자동 전환, 새 학습 입력·D03 전체 완료는 아니다.

이 조건은 앞으로 실행할 인수다. 이번 S6에서 위 6개를 통과한 것으로 표시하지 않는다. 최종 마감 보고/학습 계약이 없는데 임시 보고를 ‘완성된 통합 손익’으로 내보내지 않는다.

## 🔬 수익성·AI 검증으로 넘어가는 기준

[PRF-01~09 검토](PROFITABILITY_ADVERSARIAL_REVIEW_20260928.md)와 [P0 사전진단](PROFITABILITY_DIAGNOSTIC.md)을 유지한다. 자료 권리·요금 확인과 읽기 전용 진단 설계는 장부 연결과 병행 가능하다. 실제 자료 수집은 별도 G1 승인, 수용은 G2 검사가 필요하다.

- 합성 관통 인수는 비용·제어의 정합성 증거다. 고정 경로의 양수 손익이나 기존 합성 ridge 결과를 시장 수익성으로 해석하지 않는다.
- 실제 기준선 평가는 사용할 시장/기간에 맞는 자료·요율·시점·운영비 계약을 먼저 갖춘다. KRW 부분 인수로 미국 ETF/혼합 통화까지 검증됐다고 하지 않는다.
- 최초 비교는 동결한 기존 규칙과 비용 후 기준선이다. 후보/AI의 추가 효과는 사전 고정한 별도 비교에서 MDD·꼬리손실·회전율·비용·미체결·보류·결측·지연을 함께 평가한다. 같은 초기 자금/시장 시계에서 별도 계좌로 재생한다.
- 특징은 판단 당시 사용 가능했던 원자료로 재계산한다. 청산 손익·나중 운영비·미래 q05를 입력 특징에 넣지 않는다. 라벨은 확정 배분까지 모두 이용 가능해진 시각 이후에만 쓴다. 동일 진입 의도의 다른 스냅샷을 독립 표본으로 늘리지 않는다.
- 학습 입력의 적격 판정은 모델 학습·등록·거래 승격 권한과 다르다. 런타임 AI는 제안만 하며, 신규 유료 AI 호출과 외부 자료 전송은 이번 계획으로 승인되지 않는다. 보호·취소·장부가 AI 응답을 기다리지 않는다.

전체 D03의 미확정 범위를 숨기지 않되, 모든 미래 기능을 먼저 완성해야만 읽기 연구를 시작할 수 있다고 제한하지도 않는다. 연구 범위에 필요한 비용 연결이 갖춰졌는지를 명시하고, 원래 OOS·표본/승격 조건을 변경하지 않는다.
