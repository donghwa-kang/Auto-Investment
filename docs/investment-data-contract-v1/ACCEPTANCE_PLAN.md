# 투자 자료 수용·거래 보류 시험 명세 v1

이 문서는 [자료 계약](README.md)의 후속 구현을 위한 수용시험 계획이다. 아래 **34개 시험 그룹은 명세 작성 당시 모두 `NOT_RUN`**이다. 후속 [운영비 오프라인 연결 1단계](OPERATING_COST_ESTIMATION_STAGE1.md)에 일부 제품 합성 시험과 미지원 범위를 별도 대응표로 기록했다. 부분 구현·기존 합성 시험 이력을 새로운 실제 공급원·자료·비용 계약 전체 통과로 옮겨 적지 않는다. 명세 작성 당시 문서 참조·정책값·예시 산술 검사는 제품 수용시험과 별개다.

## 🧭 수용 상태와 권한 경계

자료별 상태는 `문서 확인 → 이용 조건 확인 → 승인된 제한 수집 → 형식/시점/커버리지 대조 → 모의 연구 수용`으로 나눈다. 이는 후속 작업 순서이며 실행 명령이 아니다. 수익성 검증·모델 승격·실주문 승인은 이 상태와 별개다.

- 현재 모든 신규 실제 공급원 수집·외부 AI 전송·실주문은 `HOLD`다. 공개 설명서 열람과 자체 합성 자료의 오프라인 검토만 이번 범위다.
- 공개 접근 가능, 키 발급 완료, API 응답 성공, 형식 검사 통과는 각각 다른 증거다. 어느 하나도 사용권·완전성·투자 적합성을 대신하지 않는다.
- 미정 입력은 0·빈 목록·오늘 날짜로 채우지 않는다. 선택 모듈을 사용하지 않는 등록 버전만 `NOT_APPLICABLE`을 허용하며, 필수 안전 입력을 선택 항목으로 낮추지 않는다.
- 제한된 자료·상품으로 통과한 시험은 같은 공급원 전체 시장, 다른 상품·통화·세션으로 확대하지 않는다. `TEST_ONLY` 자료를 실제 자료로, 실제 자료를 `TEST_ONLY`로 재표기하지 않는다.

## 🛑 보류 범위 계약

다음은 구현될 동작의 요구사항이며 현재 실주문 기능의 존재를 뜻하지 않는다.

| 원인 | 보류 대상 | 유지할 일 |
| --- | --- | --- |
| 저장·모델 사용권 미확인 | 해당 용도의 자동 수집·보관·전송 자체 | 공개 문서 조사와 허가 조건 확인 |
| 한 종목의 결측·상충·기업행동 미확정 | 그 종목 및 그 자료를 이용하는 후보 | 기존 신원·보유·주문 기록, 보호 상태 대조 |
| 모집단·벤치마크·안전 공시 공급 불완전 | 해당 모집단·벤치마크·공급원에 의존하는 선정/신규 진입 | 무관한 범위의 독립 수용검사, 기존 보호 |
| 공통 시계·자금·비용 원장 불일치 | 공통 계좌 범위 신규 진입/새 지출 | 장부·주문 대조와 경고, 보호 서비스 |
| 비활성 LLM·테마 보조 입력 없음 | 그 입력을 요구하지 않는 버전에는 영향 없음 | Q/QT의 공시·이벤트·정지 안전 검사 |
| 학습 라벨·배분 미확정 | 해당 학습 자료와 새 모델 승격 | 기존 검증 버전, 보호·대조 |

영향 범위를 증명할 수 없으면 이유와 의존 관계를 기록하여 더 넓게 보류한다. 자료 보류나 목록 편출은 기존 보호 주문 취소·무조건 청산 사유가 아니다. 다만 유효한 가격·확정 잔여 수량·검증된 청산 프로필이 없으면 임의 대체 매도/시장가 전환도 금지하고 `EXIT_BLOCKED`·알림·대조 상태로 둔다. 복구 후 재평가해도 신호의 원래 유효시간을 연장하거나 위험 래치를 자동 해제하지 않는다. 근거: [원본 가이드](../../outputs/AI_TRADING_GUIDE_v2.3.md) 303–314행, [정책](../../outputs/AI_TRADING_POLICY_v2.3.json)의 실행·승인 결합 계약.

## 📦 시험 증거 형식과 완료 조건

후속 실행은 새 전용 자료 묶음으로 수행한다. 실제 수집은 [공급원 등록부](SOURCE_REGISTER.md)의 **G1 제한 수집 승인** 이후에만 가능하다. G1은 해당 수집·보관의 권리/비용·접근·예산 확인이며, 수집 후의 G2 품질 수용 결과를 선결조건으로 요구하지 않는다. 외부 AI 전송 등 사용하지 않는 용도는 별도 HOLD로 유지할 수 있다.

시험 결과에는 `test_id`, 실행 유형(합성/허가된 실자료), 명세·정책·어댑터·자료 해시, 시장/상품/시간 범위, 입력 coverage, 기대값, 실제값, 포함/제외 사유, 판정, 오류, 검사 명령/버전, 검토자를 기록한다. 외부 증거와 로컬 생성 예시를 구분하며 키·계좌번호는 넣지 않는다. 로그·원문 보존 역시 사용권 범위 안에서만 한다.

완료 조건은 정상/반례·경계·재현 실행 결과와 독립 대조가 모두 있고, 실패/미확인/건너뛴 경우가 남아 있는 상태를 숨기지 않는 것이다. 실자료 샘플 수, 대조 오차 허용폭, p95 수집 지연·회복 목표, 출처별 TTL 등 미정 값은 임의 기본값으로 넣지 않고 해당 프로필 수용을 보류한다. 시간·가격 단위, 필수 coverage를 먼저 확정한다.

명세 단계의 완료는 요구–출처–시험–미결정의 추적 가능성이다. 실제 연결 성공이나 투자 성과 검증, ‘완벽한 거래 기준’ 인증이 아니다. 다음 구현은 외부 권리 확인과 독립적으로 가능한 **완료 위험일 창·운영비 산술의 오프라인 수정**부터 제한할 수 있다. 실제 비용 장부·환불·외화 환산·연속 손실/학습 배분은 OC-U01~OC-U08 결정 전 자동 적용하지 않는다.
