# 자동화 투자 플랫폼에서 참고할 점

2026-09-14 공식 문서의 기능 설명을 제한적으로 비교했다. 해당 서비스를 가입·유료 실행·실계좌 운용한 성능 비교가 아니며, 국내 개인의 이용 가능 여부·세금/규제·가격 경쟁력을 확인한 문서도 아니다. 서비스에 설명이 없다는 이유로 그 기능이 없다고 단정하지 않는다.

## 공식 기능과 반영 범위

| 비교 대상    | 공식 문서에서 확인한 강점                                             | 이 프로젝트에 반영/남은 범위                                                                                           |
| ------------ | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| QuantConnect | 같은 기간·시작 자금 조건의 실거래와 OOS 백테스트 손익/체결을 대조     | 판단·자료·모델 버전/해시 보존을 강화. 실제 계좌와 백테스트의 대조 기능은 아직 없음                                     |
| QuantRocket  | 학습/시험 구간을 이동하며 재학습하는 순방향 검증, 모델과 결과 저장    | 등록한 fold별 train-only 표준화·ridge·평균 기준 모델 비교와 계수 저장 구현. 대규모 ML·실제 자료·실주문과 동등하지 않음 |
| Composer     | 백테스트와 실거래의 자료/시각 차이, 슬리피지·구독비 등 비용 가정 명시 | 비용을 명시한 순 R 라벨과 보고서 한계를 표시. 무거래일 연구비 배분·계좌 손익·실제 비용 추정은 미완료                   |

근거: QuantConnect는 실거래 기간에 맞춘 OOS 곡선과 주문 체결을 비교해 비현실적 가정이나 데이터 차이를 조사하는 방법을 설명한다. 이를 실제 운용 검증의 목표로 참고했으며 해당 서비스의 지표 문턱을 우리 원본 정책에 복사하지 않았다. [공식 대조 안내](https://www.quantconnect.com/docs/v2/research-environment/meta-analysis/live-reconciliation).

QuantRocket은 순방향 학습/시험, rolling·expanding window, 전처리·모델 조합과 학습 결과 저장을 제공한다. 우리 모듈은 이 검증 방식 중 작은 범위만 구현하며 해당 제품의 코드·모델 파일을 복제하거나 사용하지 않는다. [공식 ML 검증 안내](https://www.quantrocket.com/docs/#walk-forward-backtesting).

Composer는 백테스트의 가정과 실거래의 차이, 비용 포함 설정, 적절한 비교 지표 선택을 설명한다. 플랫폼마다 가정이 다르므로 표시 수익률을 그대로 비교하지 않는다는 원칙을 참고한다. 이 문서에서 현행 구독료나 실제 총비용을 비교하지 않는다. [공식 백테스트 안내](https://help.composer.trade/article/67-backtest-basics).

## 우리가 살릴 장점

- **사용자 범위에 맞는 통제:** 원화/달러·소액 자금·위험도·지정 제외 상품을 공통 정책으로 유지한다. 학습 모듈은 해당 한도나 보호 규칙을 수정할 권한이 없다.
- **근거를 남기는 변경:** 입력·모델·계수·예측·비용·실패를 함께 보존해 어떤 자료로 결과가 달라졌는지 확인한다. 좋은 결과만 남기기 위한 반복 평가를 같은 등록 DB에서 제한한다.
- **비용과 불확실성을 분리 표시:** 현재 모델의 예측 오차와 실제 투자 수익성을 구분하고, 예측 손실 분위수/체결/자료 프로필이 없으면 모의·실주문 승인을 하지 않는다.
- **로컬 연구의 비용 통제:** 이번 작은 모델은 기존 Node 런타임에서 실행하며 모델 다운로드·GPU·유료 AI API·외부 계정이 필요 없다. 데이터 구매·향후 AI 사용·운영 비용이 영구히 0이라는 뜻은 아니다.
- **시험과 기존 운용의 분리:** 새 연구 저장소를 사용하고 기존 사용자 서버·모의 장부·원본 기준은 보존한다. 장애/노출 기록을 자동 초기화하지 않는다.

위 항목은 프로젝트의 설계 방향과 확인된 구현 특성이지 경쟁 제품에 없는 독점 기능 또는 더 높은 수익률의 증명이 아니다. 현재 상용 플랫폼 수준의 실제 데이터 공급·체결 연동·운영 지원·다양한 전략/UI·장기 신뢰성을 제공한다고 주장할 근거는 없다.

## 실전성을 판정할 다음 증거

1. 허용된 실제 자료의 정확성·정정·과거 시점 가용성, 상품/벤치마크·이용 조건과 보관 권리.
2. 기존 모의 엔진의 판단·실제 재생된 체결/비용을 자동 연결하고 원천 자료로 특징을 재계산한 기록.
3. 모델별 학습/시험/최종 holdout 구분, 전체 실험 기록·반복 비교 보정, 실제 예측 손익/하방 위험 교정.
4. 원본과 동일한 자금/위험/실행 조건의 계좌 일별 순손익·낙폭·비용 비교와 주문 없는 전진 모의검증.
5. 별도 승인된 브로커 읽기/체결·복구·장기 운영 검증. 실주문 전환은 그 이후의 독립 승인 사항.

원본 정책의 요구 기간/문턱을 이 목록으로 낮추지 않는다. 이번 완료 범위는 [오프라인 학습 실험실](LEARNING_LAB.md), 현재 실제 준비도는 [기준·구현 대조](PHASE2_READINESS_AUDIT.md), 실행 근거는 [진행 기록 · 공개 요약](PROJECT_STATUS.md)에서 확인한다.
