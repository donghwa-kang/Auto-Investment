# 위험도·차트 기준 개정 검토 v2.3

검토일: 2026-09-11. 범위는 정책 명세 수정이며 프로그램 구현·계좌 연결·주문·환전·유료 데이터 구매를 수행하지 않았다.

## 결론

상·중·하 선택은 추가할 가치가 있다. 다만 수익 목표나 신호 신뢰도의 이름이 아니라 상대적인 계획 노출로 정의했다. 상은 기존 최대 상한과 같고, 하/중은 그 1/4·1/2다. 기본 화면 제안은 하이지만 실제 선택 확인은 아직 없으며 현재 정책은 PAPER·실거래 비활성 상태다.

차트의 기존 돌파 B·눌림 P 진입 수치는 유지했다. 추가 지표의 수익성이 입증되지 않았기 때문에 ADX·볼린저 밴드폭을 실제 필수 필터로 바로 넣지 않았다. 조건별 근거 기록을 추가하고, 지표는 한 번에 하나씩 분리 검증할 계획으로 명세했다.

## 수치의 지위와 의도적인 보존

1/4·1/2·1은 소액 운용의 계획 노출을 분리하는 제안값이지 최적화 결과나 업계 공통 표준이 아니다. A=K=500만 원, PILOT, 낙폭 축소 없음에서 회당 계획 위험은 1,250/2,500/5,000원이다. 수수료·슬리피지·고정 운영비 때문에 작은 수준에서는 거래가 성립하지 않을 수 있으며 조건을 낮춰 거래를 강제하지 않는다.

기존 capital·risk·risk_calendar·universe·economic_gate·execution·exit_policy·ledger·price_data·security·broker_evidence 값과 B/P 수치·전략 정의를 보존한다. 외화 자산 40%와 일·주·월 중지선도 그대로다. LOW라는 이름이 환위험이나 갭 위험을 없애지는 않는다. 기존 API 확인 일자를 이번 차트 개정일로 갱신하지 않았다.

## 차트 연구의 근거와 한계

ADX는 추세 강도를 나타내며 방향 지표가 아니다. 25 경계는 공개 설명에 쓰이는 값이지만 이번 매매의 수익성이 검증된 값은 아니다. [Fidelity ADX 설명](https://www.fidelity.com/viewpoints/active-investor/average-directional-index-ADX)

볼린저 밴드 접촉 자체는 매매 신호가 아니고, 상관된 지표의 중복 확인을 경계해야 한다. 이 원칙을 반영해 RSI·MACD 등 다수 지표의 투표 점수 대신 기존 B/P와 개별 필터의 추가 가치를 비교하도록 했다. 밴드폭 20/2·60세션·20백분위수 조합은 별도 시험 가설이다. [Bollinger 공식 규칙](https://www.bollingerbands.com/bollinger-band-rules)

손절가에서 체결을 보장할 수 없고 스톱리밋은 미체결일 수 있으므로 계획 위험을 실제 손실의 최대치라고 부르지 않는다. [SEC 투자자 안내](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15)

연구안은 B_BASE/P_BASE/B_ADX/P_ADX/B_BBW의 다섯 개, 비교는 세 쌍이다. 추가 필터 채택은 기존 절대 문턱·전향 모의·체결 검증에 더해, 같은 위험도의 공통 달력에서 비용 차감 증가분 부트스트랩 하한>0 및 최대 낙폭 비악화를 시험한다. 엄격한 채택 기준 자체가 효과를 입증하지는 않는다. 위험 수준별 결과를 섞지 않고 실제 배포할 조합별로 검증해야 한다.

## 이번 검증

PowerShell 7.6.5에서 최종 오프라인 검사 248/248 통과, 실패 0, 종료 코드 0을 확인했다. 최초 247개 검사 후 테마의 증분 검증 참조를 공통 v2.3으로 정리하고 모의 프로필 해시와 LIVE 검증 기록의 구분을 추가하여 전체를 재검사했다.

검사 범위는 전체 필드 고정 JSON Schema, 100만/300만/500만 원과 세 수준·단계·낙폭 조합의 상한, 수량·비용·잔여 위험, 가상 수준 변경 상태, 판단 스냅샷 결합, ADX/밴드폭의 독립 합성 사례, 문서의 Markdown 변환·표 셀·내부 링크 및 제한적인 민감정보/깨진 문자 패턴이다. 이전 16개 산출물의 SHA-256 일치도 확인했다. Git 저장소가 아니므로 커밋/푸시나 Git 전체 기록 검사는 하지 않았다.

- 정책 전체 필드 고정 스키마는 명세 산출물의 회귀 검사다. 운영 환경에서 사용자가 입력할 모든 설정을 검증하는 범용 런타임 스키마가 아니다.
- 독립 수학 함수·가상 상태 판정은 정책의 계산 예시만 검사한다. 거래 엔진·실제 동시성·네트워크·인증의 통과를 뜻하지 않는다.
- 실제 시장 백테스트, 비용 데이터, 세 단계별 성과·위험 순서, 실행 UI, 체결·취소 경쟁 상태, 실계좌 자격 검증은 미수행이다.
- Markdown 구조 검사와 실제 화면 검토는 다르다. 기존 로컬 미리보기 보안 차단을 우회하지 않으며 시각 검토 두 항목은 미완료로 남긴다.

## 남은 구현·승격 조건

공유 평가기·정밀도/벤치마크/체결/예측/청산 프로필·감사 기록·선정 함수 등 기존 미확정을 유지한다. 추가로 위험도 설정 화면, 인증 확인, 설정 epoch, 공통 잔여 위험, 변경 중 취소/부분 체결 복구, 선택 수준별 검증 기록과 조건별 차트 추적이 필요하다. ADX·밴드폭 추가 가치는 미검증이며 현재 비활성이다.

현재 risk_level_contract.runtime_implemented=false, selected_level=null, validation_records=[], chart_research.enabled=false, execution_adapter=NONE, live_enabled=false다. 이 문서를 생성했다고 실행 가능한 자동매매 프로그램이 된 것은 아니다.
