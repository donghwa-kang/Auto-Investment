# AI 자동매매 정책 검토·검증 보고서 v2.1

검토일: 2026-09-10. 대상: 공통 v2.0 → v2.1, 테마 v1.0 → v1.1. 이번 작업은 명세·설정·독립 계산·수용시험 정의이며 실제 거래 프로그램을 구현하지 않았다.

## 1. 전체 판정

**오프라인 위험 계산기·장부·가상 체결기·상태 관리의 구현에는 착수할 수 있다. 실거래 활성화와 테마 자동 선정의 운영 준비는 끝나지 않았다.** 이번 파일은 설정 명세(`specification_not_executable`)이고 실행 가능한 프로그램 구성으로 인증된 것이 아니다.

초기 상태는 PAPER, live_enabled=false, execution_adapter=NONE, 전략 UNVALIDATED, 테마 enabled=false, 기본 MARKET_SCAN이다. SOXL은 조사·감시 전용이다. 500만 원 이하 입력·공통 위험 한도·당일 최대 90분 보유를 유지했다. 수익성이나 손실 상한을 보장하지 않는다.

검토에는 code-reviewer 스킬의 근거·호출 계약·경계 조건 점검 원칙을 적용했다. 사용자가 이번 요청에서 명시적으로 승인한 개정 문서·설정·검증 스크립트만 작성했다. API 키 입력, 계좌 연결, 주문, 환전, 유료 가입, 예약 작업, 보안 설정 변경은 하지 않았다.

### 2.3 숫자와 규칙의 지위

기존 위험 비율·PILOT/낙폭 축소 배수·B/P 신호·보유기간·표본 수는 변경하지 않았다. 외화·낙폭·비용의 계산 해석과 모드 권한 계약을 수정했다. 원래 설정에서 유지된 값은 오프라인 대조한다.

새 조회 목표 1초·무진전 평가 2초·대체 주문 최대 2회는 **미검증 시험값**이다. 호출 한도·세션·실제 지연을 반영해 시험해야 하고 최적값으로 사용하지 않는다. 최대 불리한 청산 가격 범위는 임의로 채우지 않고 null이다. 운영비 0건 대안은 승인된 당일 잔여 예산이 없으면 보류한다.

공식 상품·API·제도 설명은 확인 사실, 중복 주문 방지·권한 분리·장부 일치는 필수 운영 규칙, 수익성 수치·신호·새 타이머는 시험 가설, 계좌·청산 가격·테마·공급 계약은 미확정 사항이다. 필수 규칙을 명세했다고 구현이 검증된 것은 아니다.

## 4. 수행 검증과 결과

### 4.1 수행 범위

검증 환경: Windows, PowerShell 7.6.5. 별도 설치·증권사 라이브러리·실계좌 자격증명·네트워크를 검증 스크립트에서 사용하지 않는다.

프로젝트 루트에서 재실행:

```powershell
pwsh -NoProfile -File work/validate_policy_v2_1.ps1
```

스크립트는 표준 출력에 항목별 결과와 총계를 내고 실패가 있으면 종료 코드 1을 반환한다. work의 두 JSON Schema는 **이번 초기 명세의 모든 필드·타입·추가 키·일부 범위·고정 안전값을 확인하는 정적 스키마**다. 미래 설정 변경 전체를 지원하는 런타임 검증기로 주장하지 않는다.

최종 실행: **120개 검사 통과 / 실패 0, 종료 코드 0**. 각 검사는 하나 이상의 단언을 포함하므로 120은 검사 묶음 수이며 개별 단언 수나 거래 횟수가 아니다.

| 검사 묶음 | 통과/전체 |
| --- | --- |
| 설정·자금·한도·외화·낙폭·비용·수량·경제성 | 61/61 |
| 모드 권한·승인 스냅샷 변경 | 34/34 |

| 문서 정적 검사·기존 네 파일 보존 | 14/14 |

첫 실행에서 검증 도우미 인자명과 파일 반복 변수의 이름 충돌로 문서/보존 12개가 실패했다. 검증 도우미의 변수 범위를 수정하고 전체를 다시 실행하여 위 결과를 확인했다. 산식 검산 실패나 증권사 오류가 아니며 실패를 제외해서 통과 수를 만든 것이 아니다.

검사에는 JSON 파싱/스키마 및 잘못된 설정 거절, 기존 정책 값 보존, 자금 입력 경계, 한도·외화·낙폭·운영비·수량·경제성 독립 검산, 가상 권한 진리표, 승인 필드 변경 무효화, 보호 상태 명세, 기업행동, 달력 예제, 내부 링크·Markdown 구조·민감정보 제한 패턴·원본 SHA-256 보존을 포함한다.

### 4.3 해석 제한

검산용 함수와 가상 권한 판정은 거래 엔진의 구현이 아니다. 특히 PAPER → 실제 주문 접근 금지는 **현재 명세와 독립 모형에서의 목적지 판정**만 확인한다. 실제 프로세스의 import 격리·자격증명 주입·네트워크 송신 방지는 향후 구현에서 별도 시험해야 한다.

수량·예약·중복 이벤트 사례를 통과해도 실제 동시성·원자성·API 멱등성·부분 체결·주문 취소 경합이 입증되는 것은 아니다. 가격/환율은 합성 값이며 실거래 수수료·성과·최대 낙폭은 측정하지 않았다. 민감정보 검사는 이번 다섯 산출물의 제한된 패턴 검색이며 전체 Git 이력·모든 개인정보 형식의 보안 감사가 아니다.

Markdown 변환·표 셀·링크 실재는 정적 검사다. 실제 앱 화면의 표·코드·줄바꿈은 미검증이다. 기존 로컬 파일 미리보기 보안 차단을 다른 브라우저·서버·경로로 우회하지 않았다.

향후 수용시험은 공통 가이드 15·23절과 테마 가이드 10·12절을 따른다. 입력·상태·요구 결과는 정의했지만 실제 엔진이 없으므로 미실행으로 남긴다. 별도의 사용자 결정이 필요한 항목은 해당 기능만 차단하고, 연구·계산 검증까지 일괄 중단하지 않는다.
